# 🎓 Campus Placement Portal

A web-based **Campus Placement Portal** developed as a BCA project to manage the complete campus recruitment process for students, companies, and administrators.

## 🚀 Features

### 👨‍🎓 Student Module
- Student registration and login
- View available job opportunities
- Search jobs by title, company, or location
- Apply for jobs
- View submitted applications
- Track application status
- Logout functionality

### 🏢 Company Module
- Company registration and login
- Post new job opportunities
- View posted jobs
- Delete posted jobs
- View student applicants
- Shortlist applicants
- Select applicants
- Reject applicants

### 👨‍💼 Admin Module
- Secure admin login
- Dashboard statistics
- View registered students
- View registered companies
- View posted jobs
- View all applications
- Delete students, companies, jobs, and applications
- Search and manage records

## 🛠️ Technologies Used

### Frontend

### Backend
